# Relern Operating Notes

Use Relern when the user asks about their real classes, coursework, deadlines, files, rubrics, announcements, modules, discussions, messages, or planner items.

## Rules

1. Treat Relern and Canvas as the source of truth for live academic data.
2. Use this repository for notes, drafts, plans, and durable working memory.
3. Do not invent course facts.
4. Re-check live course data before making decisions on deadlines, requirements, or submissions.
5. Before write actions like sending messages or posting content, ask for explicit confirmation.

## Recommended workflow

1. Identify the relevant course.
2. Fetch the needed live context from Relern.
3. Produce the answer or output.
4. Save durable notes or drafts into this repo when useful.

## Good places to write

- course-specific context: `courses/`
- temporary or cross-course notes: `notes/`
- planning: `planner/`
- session memory: `memory/`
- unfinished output: `drafts/`
