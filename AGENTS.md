# AGENTS.md

## Cursor Cloud specific instructions

This repository is a **Markdown-only workspace** (no code, no dependencies, no build steps, no services).

- **No install/build/test/lint commands exist.** There is no `package.json`, `requirements.txt`, `Makefile`, or any other dependency manifest.
- The repo is an agent-first academic scratchpad. The core workflow is reading and writing Markdown files in the folder structure described in `README.md`.
- Live academic data comes from the **Relern MCP** (external service, not bundled here). Connect it via your tool's MCP configuration.
- See `README.md` for folder layout, agent operating rules, and recommended workflow.
- See `prompts/agent-checklist.md` for the operational checklist agents should follow before and after tasks.
