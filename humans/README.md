# Human Handoffs

This folder is for short notes from models to humans.

Use it for:
- completed task summaries
- session handoff notes
- open questions
- risks or blockers
- pointers to files changed elsewhere in the repo

Suggested note format:
- model/tool name
- date
- task completed
- key changes
- follow-up needed

Models should review the latest repo state before adding a new note so they do not write handoffs against stale work.
