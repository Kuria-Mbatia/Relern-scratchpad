# Getting Started

## What this repo is for

This workspace gives AI tools a clean place to write while Relern handles live academic retrieval from Canvas.

Use this repo when you want:
- notes that persist across sessions
- draft outputs saved to files
- structured assignment workspaces
- a writable memory layer for coding-oriented tools

## What to store here

- assignment summaries
- course overviews
- study plans
- meeting notes
- draft messages
- generated study guides
- saved prompts

## What not to treat as canonical

- official due dates
- grades
- instructor announcements
- assignment instructions
- rubric details

Those should always be re-checked through Relern before acting on them.

## Suggested first steps

1. Rename `courses/_template` when you start working on a real course.
2. Add your current priorities to `planner/upcoming.md`.
3. Save reusable preferences in `memory/preferences.md`.
4. Keep session-level scratch work in `memory/session-notes.md`.
